# 5VINCI Monitor

Программа для Windows: загрузка процессора (общая и по ядрам), память, температуры, видеокарта, диски, скорость сети, список процессов и история нагрузки за 24 часа. Тёмный оранжевый интерфейс.

## Как запустить у себя для проверки
1. Установи Node.js 22 с nodejs.org.
2. В папке проекта выполни `npm install`, затем `npm start`.

## Как получить .exe для скачивания (без терминала)
1. Создай на GitHub новый репозиторий (например `5vinci-monitor`).
2. Add file → Upload files: перетащи всё содержимое папки (вместе с `.github`, `renderer`, `build`). Commit changes.
3. Вкладка Actions → «Сборка программы для Windows» → Run workflow. Через 4–6 минут внутри запуска появится файл для скачивания.
4. Чтобы была постоянная ссылка: Releases → Draft a new release → тег `v1.0.0` → Publish. Сборка запустится сама, и установщик появится в этом релизе.

Файлы: `5VINCI-Monitor-1.0.0-nsis.exe` (установщик) и `5VINCI-Monitor-1.0.0-portable.exe` (запускается без установки).

Windows может показать «Защитник Windows предотвратил запуск». Это потому, что программа не подписана. Нажми «Подробнее» → «Выполнить в любом случае».

## Температуры
Windows не отдаёт температуру процессора обычным программам. Если пишет «нет данных», запусти программу от имени администратора. У части компьютеров данных нет вообще: это ограничение системы.
