# 5VINCI Optimizer

Программа для Windows в стиле магазина приложений: всё в одном окне, без поиска настроек по папкам.

- **Проверить и ускорить**: одна кнопка. Программа смотрит, что можно улучшить, показывает список, ты снимаешь лишние галочки, нажимаешь «Применить» и видишь, что изменилось.
- **Интернет**: быстрый DNS, сброс сети, отключение раздачи обновлений другим.
- **Батарея и питание**: планы электропитания, экономия заряда, запрет фоновых приложений.
- **Производительность**: игровой режим, отключение фоновой записи игр, меньше анимаций.
- **Службы Windows**: телеметрия, Xbox, печать, поиск и другие службы, которые можно выключить.
- **Автозагрузка**: что запускается вместе с Windows, с переключателями.
- **Очистка диска**: временные файлы, кэш обновлений, браузеров, корзина.
- **Мониторинг**: процессор, память, температуры, диски, сеть, процессы, история за 24 часа.
- **Журнал изменений** и кнопка «Вернуть всё как было». Перед изменениями создаётся точка восстановления Windows.

Программа просит права администратора: без них Windows не даёт менять службы и реестр.

## Как получить .exe (без терминала)
1. На GitHub создай репозиторий (например `5vinci-optimizer`).
2. Add file → Upload files: открой папку проекта на компьютере, выдели всё содержимое (Ctrl+A) и перетащи в окно браузера. Папки (`.github`, `renderer`, `build`) загрузятся вместе с файлами. Если папка `.github` не загрузилась (она скрытая), создай файл руками: Add file → Create new file → имя `.github/workflows/build.yml` и вставь текст из этого файла.
3. Commit changes.
4. Вкладка Actions → «Сборка программы для Windows» → Run workflow. Через 4–6 минут внутри запуска, внизу, будет файл для скачивания.
5. Постоянная ссылка: Releases → Draft a new release → тег `v1.0.0` → Publish release. Установщик появится в этом релизе.

Файлы: `5VINCI-Optimizer-1.0.0-nsis.exe` (установщик) и `5VINCI-Optimizer-1.0.0-portable.exe` (без установки).

## Предупреждение Windows
Файл не подписан сертификатом, поэтому SmartScreen напишет «Windows защитила ваш компьютер». Нажми «Подробнее» → «Выполнить в любом случае». Подпись стоит денег (около 200–400 $ в год), на работу программы не влияет.

## Температуры
Windows не отдаёт температуру процессора обычным программам. У части компьютеров данных нет вообще: это ограничение системы.

## Для проверки у себя
Node.js 22, в папке проекта `npm install`, затем `npm start`.
