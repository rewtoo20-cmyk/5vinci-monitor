# 5VINCI Optimizer 2.0

Программа для Windows 10 и 11 в стиле магазина приложений: всё в одном окне. Вход по ключу.

## Что умеет (56 пунктов)
- **Проверить и ускорить**: одна кнопка, список находок с галочками, потом отчёт, что изменилось.
- **Интернет**: быстрый DNS, не раздавать обновления, проверка пинга, очистка DNS, обновление IP, сброс сети.
- **Батарея и питание**: планы электропитания, экономия с 30%, запрет фоновых приложений, гибернация, быстрый запуск, USB, отчёт о батарее.
- **Производительность**: игровой режим, приоритет играм, быстрые меню, быстрое выключение, без ускорения мыши, HAGS, освобождение памяти и другое.
- **Приватность**: реклама, телеметрия, история действий, поиск Bing в Пуске, отчёты об ошибках.
- **Проводник и вид**: расширения файлов, скрытые файлы, тёмная тема, полное меню Windows 11, виджеты, секунды в часах, залипание клавиш и другое.
- **Службы Windows**: телеметрия, Xbox, SysMain, печать, поиск, RDP и другие.
- **Автозагрузка**, **очистка диска** (14 видов: Windows, браузеры, Discord, шейдеры, миниатюры, дампы), **мониторинг**, **журнал** и «Вернуть всё как было». Перед изменениями создаётся точка восстановления.

## Ключи входа
1. Открой файл `5VINCI-Keygen.html` двойным щелчком (лежит отдельно, в архив с программой он НЕ входит и в GitHub его загружать нельзя).
2. Впиши имя клиента, выбери срок, нажми «Создать ключ», скопируй длинный ключ и отправь клиенту.
3. Если нужно привязать ключ к одному компьютеру: клиент присылает ID с экрана входа, ты вписываешь его в поле «ID компьютера». Тогда ключом нельзя поделиться.
4. Ключи хранятся в списке на странице генератора (только в этом браузере).

Ключ подписан цифровой подписью (Ed25519). Без закрытого ключа из файла Keygen подделать или подобрать ключ нельзя. В программе лежит только публичный ключ (`pubkey.js`).

Если закрытый ключ утёк: в Keygen раздел «Дополнительно» → «Создать новую пару», вставь новый публичный ключ в `pubkey.js` на GitHub и пересобери. Все старые ключи перестанут работать.

Отзыв ключа: в `license.js` есть строка `REVOKE_URL`. Выложи на свой сайт файл со списком id ключей (`["abcd1234"]`) и впиши его адрес: программа раз при запуске скачает список и закроет доступ этим ключам.  id ключа виден в Keygen в таблице созданных ключей.

## Защита (честно)
Сделано: подпись ключей, проверка ключа в главном процессе (а не в окне), привязка к компьютеру, срок, защита от перевода часов назад, ограничение попыток ввода, запрет отладчика и запуска Electron как Node, закрытые окна и навигация, строгая политика CSP, проверка всех команд от окна, список защищённых процессов, команды PowerShell только из заранее заданного списка.
Нельзя: полностью защитить программу на чужом компьютере. Человек с навыками может распаковать приложение и вырезать проверку. Для настоящей защиты нужна проверка ключа на твоём сервере (можно сделать на Cloudflare), это следующий шаг.

## Как получить .exe (без терминала)
1. Загрузи содержимое папки на GitHub (Add file → Upload files): все файлы и папки, КРОМЕ `5VINCI-Keygen.html`. Папка `.github` скрытая: если она не загрузилась, создай файл `.github/workflows/build.yml` вручную и вставь текст из этого проекта.
2. Actions → «Сборка программы для Windows» → Run workflow. Через 4–6 минут внизу запуска, в разделе Artifacts, будет файл.
3. Внутри: `5VINCI-Optimizer-Setup-2.0.0.exe` (установщик) и `5VINCI-Optimizer-Portable-2.0.0.exe`.

Если включён Smart App Control, Windows блокирует программы без платной подписи. Подпись кода стоит примерно 200–400 $ в год.

## Температуры
Windows не отдаёт температуру процессора обычным программам. У части компьютеров данных нет: это ограничение системы.
